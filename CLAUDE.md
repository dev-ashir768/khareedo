## ⚠️ Next.js version warning

This project pins `next@16.3.2`, newer than your training data. APIs, conventions, and file structure may differ from what you expect (example: `app/layout.tsx` types its props as `LayoutProps<"/">`, a typed-route helper Next.js generates itself, not a hand-written type). **Before writing Next.js code, check `node_modules/next/dist/docs/` for the relevant guide** and honor deprecation notices there. `AGENTS.md` is regenerated by `next dev` — committing it alongside your work is fine, deleting it just brings it back.

## Architecture

Single-page storefront ("Khareedo" marketplace). Everything renders from `app/page.tsx` — one `"use client"` component holding the header, hero, search, product grid, and footer. There is no routing beyond `/`, no API layer, and no state management library.

- **Data**: `data/products.json` is a captured API response (`payload.products`) imported statically at module scope and cast to a local `Product` type. Search and price filtering are pure client-side `useMemo` over that array. Swapping in a real fetch means replacing that import, not restructuring the page.
- **Product images** are remote (`oms.getorio.com`), allowlisted in `next.config.ts` `images.remotePatterns`. Any new image host needs an entry there or `next/image` will throw.
- **Commented-out code in `app/page.tsx` is intentional WIP**, not dead code: the category chips and the Radix Popover + Slider price filter are written and disabled. `appliedRange` is still live state feeding the filter, so the plumbing works — re-enabling means uncommenting the UI (and restoring the `radix-ui`/`ChevronDown` imports at the top). Prefer completing these over rewriting them.
- **Styling**: Tailwind CSS v4 via `@tailwindcss/postcss`; no `tailwind.config` — theme lives in `app/globals.css` (`@theme inline` + oklch CSS variables, light/dark blocks).
- **shadcn/ui**, `radix-nova` style, neutral base (`components.json`). Only `button` and `card` are installed under `components/ui`. Add more with the shadcn CLI rather than hand-writing them. `cn()` is in `lib/utils.ts`.
- **Fonts**: Inter (`app/fonts.ts`, applied as `inter.className`) plus Geist Mono as `--font-geist-mono`. Note `globals.css` still maps `--font-sans` to `--font-sora`, a leftover from the commented-out Sora setup — so `font-sans` resolves to nothing; use it deliberately or fix the mapping.
- **Path alias**: `@/*` → repo root.

Icons are `lucide-react`. `react-intersection-observer` is installed but unused so far.
